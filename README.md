# Predicting Primes — Riemann Hypothesis explainer

An explainer video about how the Riemann zeta function controls the distribution of primes and what
an AI proved in autumn 2026 (the quasi-Riemann hypothesis). Built around short excerpts from the
World Science Festival interview "AI Closes In on the Riemann Hypothesis" (Brian Greene, Alex Kontorovich).

© 2026 Marko T. Manninen

## Layout

| Path | Contents |
|---|---|
| `docs/` | NotebookLM scripts (`episode_script.md`, `excursion_script.md`), production sheet, source text, YouTube metadata |
| `video/render.py` | Scene schedule (`MAIN`, `EX`, `CRED`) and the renderer |
| `video/scenes_b.py` | Current scene designs, built on `scenes_ex.py`, `scenes.py` and the theme in `lib.py` |
| `video/clips_c.py` | Builds the embedded interview clips (cut points in `SEG`) |
| `video/assemble.py` | Joins scenes, narration, interview clips and credits into one video |
| `video/mix.py` | Places music and sound effects on the assembled timeline |
| `video/build.sh` | Runs the whole pipeline from scenes to the final video |
| `video/audit.py`, `video/audit_sparse.py` | Check scenes for text outside the safe margin and for near-empty frames |
| `video/paths.py` | The one place that defines where inputs and outputs live |
| `video/art/` | Section-card artwork |
| `video/fonts/` | Inter and EB Garamond (SIL Open Font License), bundled so text renders the same everywhere |
| `data/zeta_data.json` | First 150 zeta zeros and sampled zeta values, regenerated by `scripts/make_zeta_data.py` |
| `scripts/transcribe.py` | Timestamped Whisper transcription used for narration timing (transcripts stay local in `transcripts/`) |

## Setup

The build needs Python 3.10 or newer and `ffmpeg` on the path.

```
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

## Media that is not in git

Large media stay on the local machine in `sources/`, which git ignores. Set `RIEMANN_SOURCES` to use another folder. The full build expects these files:

| File | Contents |
|---|---|
| `sources/clips/clip01.mp4` … `clip10.mp4` | Interview excerpts cut from the World Science Festival video at the times in `docs/production_sheet.md` |
| `sources/Predicting_Primes.mp4` | NotebookLM main video, used for its narration audio |
| `sources/The_Explainer.mp4` | NotebookLM excursion video, used for its narration audio |
| `sources/music/Riemann 1.*`, `Riemann 2.*`, `Riemann 3.*` | Music for the main theme, the tension parts and the breakthrough |
| `sources/music/Low_soft_whoosh*`, `Single_soft_glass_be*`, `Soft_chalk_drawing*`, `Single_soft_muted_ti*` | Whoosh, bell, chalk and tick effects |

A script that misses one of these stops and names the missing file.

## Build

Every script finds its files through `video/paths.py`, so it runs from any folder. Output goes to `build/`, or to `RIEMANN_BUILD` when that is set.

```
video/build.sh                         # full video into build/Predicting_Primes.mp4
python3 video/render.py main all       # only the main scenes into build/seg/
python3 video/render.py main 0,2 still # stills of chosen scenes into build/still/
python3 video/clips_c.py 3 5           # only interview clips 3 and 5 into build/clips/
python3 video/audit.py                 # text placement check, no rendering
```

Interview excerpts are used for commentary and education, and all rights to them remain with World Science Festival.
