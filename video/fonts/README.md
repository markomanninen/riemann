# Fonts

Both font families are licensed under the SIL Open Font License 1.1 and are bundled so that every machine renders the same text metrics.

- Inter 4.1 by Rasmus Andersson, from https://github.com/rsms/inter. The license text is in `OFL-Inter.txt`.
- EB Garamond by Georg Duffner and Octavio Pardo, from https://github.com/octaviopardo/EBGaramond12, under the same license.
